# MacBook Pro A1502 2013-2014 Not turning on (Fan spins then stops) repair

## Problem description
Green light on charger, fan starts spinning but immediately stops; loops
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Charger LED is green
- Starts up, fans spin then stop and it repeats.

## Solution
Corrosion around U7100, especially C7150, C7126, and R7152. R7152 was effectively destroyed, so no electrical connection between U7100 pin 17 and U5670 pin 4; fixed with jumper wire.
