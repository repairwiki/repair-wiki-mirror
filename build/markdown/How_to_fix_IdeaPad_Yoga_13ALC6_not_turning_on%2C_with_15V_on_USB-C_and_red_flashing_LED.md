# How to fix IdeaPad Yoga 13ALC6 not turning on, with 15V on USB-C and red flashing LED

## Problem description
Lenovo IdeaPad Yoga 13ALC6 faces a critical issue of not powering on, accompanied by a red flashing indicator, displaying 15V and 0.00A on the USB-C meter.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Red flashing light
- Drawing no current at 15V from the charging port
- Sometimes charging, sometimes not

## Solution
  - Check USB-C 5v pins**

The laptop might charge occasionally but will not power on. Despite most of the board seeming fine via multimeter, this is usually caused by the charging USB-C port (The secondary USB-C on the right does not provide power.) The blinking light indicates power fluctuation, fix by replacing the port.
