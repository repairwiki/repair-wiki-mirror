# Nintendo Switch Right Joycon pressing buttons randomly Repair

## Problem description
Fixing an issue where the right Joy-con pressing buttons randomly on the Nintendo Switch

## Symptoms
- Right Joy-con pressing buttons randomly

## Solution
Sometimes this is caused by a faulty R button. Try to re-flow the connection. If that doesn't work, try replacing it.

You may also need to run jumper wires like in the [https://youtu.be/FxrmLP0V1dk attached video].

Also make sure to clean it as good as possible, sometimes the flux gets inside the button or the alcohol hasn't fully dried yet.
