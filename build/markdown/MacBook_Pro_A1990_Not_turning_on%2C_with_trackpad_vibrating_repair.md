# MacBook Pro A1990 Not turning on, with trackpad vibrating repair

## Problem description
The MacBook seems braindead because the trackpad is reacting for 20-30 sec and then it stops and On again. On the USBC multimeter we see boot looping from 0.06 to 0.14, at 0.06 the trackpad is not vibrating and on 0.14 is vibrating. Randomly the MacBook starts but for no obvious reason and works fine, once shut down it will not restart
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Randomly the MacBook starts but for no obvious reason and works fine, once shut down it will not restart
- Vibrating trackpad
- On the USBC meter we see boot looping from 0.06 to 0.14A at 20V

## Solution
- U3000 is faulty (getting warm, 38-40 degrees Celsius)
  - Replace U3000 (Figure 1)

After replacement, the MacBook should work properly.
