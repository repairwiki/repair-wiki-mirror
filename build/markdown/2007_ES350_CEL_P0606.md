# 2007 ES350 CEL P0606

## Problem description
Check engine light Code P0606

![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Information about problem
- ECM / PCM Processor (usually not ECM may be exhaust leak or bad O2

## Solution
O2 sensor impedance was very high and didn't move also failed monitor test. Change O2 impedance started to move.

### Diagnostic Steps
Check for any exhaust leak. With scan tool check monitor and see if O2 have failed any test. Check scan data for any irregular O2 impedance levels.
