# Nintendo Wii No Power

## Problem description
The device does not turn on
## Symptoms
- No Power

## Solution
- Check power brick and make sure it's outputting 12V
- Check motherboard and make sure 12V is being deliverd to F2
- Make sure F2 isn't blown
