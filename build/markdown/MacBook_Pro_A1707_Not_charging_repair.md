# MacBook Pro A1707 Not charging repair

## Problem description
Fixing an issue with A1707 TouchBar MacBook Pro that is not charging properly.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Discharge during normal operation
- Won't charge during normal operation when plugging in charger
- Won't charge when turned off

## Solution
Charger may have gone on strike. Unplug charger from AC and from Laptop, wait a few seconds, try again. Try a different port on MacBook (the problem with the other port will go away automatically).

SMC problems may prevent charging at all. When turned off, [https://support.apple.com/en-us/HT201295 perform an SMC reset]
