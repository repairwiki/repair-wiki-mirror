# Nintendo Wii System won't insert/eject discs. System inserts/eject discs slowly

## Problem description
System won't insert/eject discs. System inserts/eject discs slowly
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- System won't insert/eject discs
- System inserts/eject discs slowly

## Solution
- Take apart disc drive, clean and inspect for broken components
- Make sure all the cables are plugged in properly and aren't damaged

- Replace disc drive
