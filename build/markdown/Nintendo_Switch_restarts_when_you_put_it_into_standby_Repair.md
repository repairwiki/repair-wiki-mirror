# Nintendo Switch restarts when you put it into standby Repair

## Problem description
Fixing a problem where the Switch restarts when you put it into standby

## Symptoms
- Switch restarts when you put it into standby

## Solution
Check the mosfets above the usb type c port, [click here to learn more about MOSFETs](Transistors_-_Repair_Basics.md) and how to check them. Replace them if faulty.
