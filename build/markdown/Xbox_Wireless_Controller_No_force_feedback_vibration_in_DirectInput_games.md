# Xbox Wireless Controller No force feedback vibration in DirectInput games

## Problem description
No force feedback vibration in DirectInput games during gameplay
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- No force feedback vibration in DirectInput games

## Solution
> Install [http://steamcommunity.com/discussions/forum/1/620703493322085771/ Force Feedback Driver for Xbox One Controllers]. Some games will still not support vibration even with this installed.
