# MacBook Pro A1989 "Braindead" repair

## Problem description
Any shorted subrail on A1989 machines can cause the machine to hang on POST.![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- MacBook hanging on POST
## Solution
- Thermal imaging can reveal abnormal heat caused by a shorted component.
- This condition is most frequently caused by a SSD subrail, such as the 2v7 SSD power line.
