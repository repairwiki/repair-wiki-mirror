# Sony WH-1000XM4 Headphones Battery Low, Please Recharge Headset Repair

## Problem description
How to fix Sony WH-1000XM4 / WH-1000XM3 headphones that say "battery low, please recharge headset" and will not charge
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Headphones are not charging.
- You hear a low battery message from the headphones.

## Solution
- If you did not just disconnect/connect the battery, put the headphones on a known good charger for about an hour.

- If you did just disconnect and re-connect the battery, power off the headphones normally then power them back on. The headphones will say this anytime the battery has been disconnected and reconnected or replaced but a reboot always fixes it.

- Use a multimeter to check the battery. Battery should read between 3.7v and 4.2v. If it's outside of this range, replace the battery with another one.
- If the above does not fix the issue and the battery voltage is good, replace the SUB_R board.
