# Nikon Z

## Limitations of the use of FLASH
Shutter type limitation based on attached lenses or based on attached lens.

Link to the manufacturer's page: https://www.nikonimgsupport.com/eu/BV_article?articleNo=000066929&configured=1&lang=en_GB

If you have any lenses on this list or no lenses, FLASH will NOT work. This is not a problem with the Z8 and Z9 models.
