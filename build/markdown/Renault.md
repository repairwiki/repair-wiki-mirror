# Renault

## Diagnostic Overview
An Overview of **Vehicle Diagnostics** for the European car manufacturer **[https://en.wikipedia.org/wiki/Renault Renault]**. The listed tools are meant for car **owners** to efficiently communicate with their cars.
### Possibilities
- **Read/Clear DTCs**: This enables the owner to readout errors specifying necessary  repair. Additionally these tools allow clearing (not deleting) of said errors. The ECU-Module will still through an error if the error is detected after clearing or deletion.

- **Activate/Deactivate features**: Exe: Activating all windows to be rolled up/down via holding key lock/unlock button.

- **[https://en.wikipedia.org/wiki/CAN_bus CAN-BUS] sniffing**: Find out what exactly is going on in the CAN-Network

## Available Diagnostic Software
### [https://github.com/cedricp/ddt4all DDT4ALL]
Before use, it will be necessary to download the ECU Information (see Github ReadMe)

A Python based program which is aims to offer an alternative to the official DDT2000 dealer software which requires a additional Renault CAN Clip Dongle.
Instead of the costly dongle, this program can work with a
  - wireless dongle** (Bluetooth or Wifi: ELM327,ELS27) or **wired dongle** (USB:ELM327, ObdLink SX) which are cheaper, more accessible and could be used by other diagnostic software.

- *If considering the **ELM327**; Please make sure it has the Original IC-Chip PIC1825K80* otherwise there will be connection errors

- For **IOS Users**, Iphone tests have shown, that only the ELM327-Wifi versions seem to be compatible with various apps.
