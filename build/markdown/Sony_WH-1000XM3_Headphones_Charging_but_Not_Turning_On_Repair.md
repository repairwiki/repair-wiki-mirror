# Sony WH-1000XM3 Headphones Charging but Not Turning On Repair

## Problem description
How to fix Sony WH-1000XM3 headphones that will not turn on.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Will not power on but appears to charge (red charging light comes on and stays lit).

## Solution
- Use a multimeter to check the battery. Battery should read between 3.7v and 4.2v. If it's outside of this range, replace battery with another one.
- Check connections, check unit for signs of water damage.
- Assuming all the above stuff is good, you have a dead L_MAIN board, replace L_MAIN board. The service manual says you can't but you can. Just make sure you solder all wires in the correct order.
