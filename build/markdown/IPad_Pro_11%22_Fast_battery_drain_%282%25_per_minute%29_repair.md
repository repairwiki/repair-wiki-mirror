# IPad Pro 11" Fast battery drain (2% per minute) repair

## Problem description
Repairing an issue with the iPad Pro 11" (2018) where the battery drains very fast, around 2% per minute.
![Power IC U8500 (Figure 1)](images/3/30/Placeholder_image.jpg)
## Symptoms
- The tablet works normally but with fast battery drain

## Solution
[Short Circuits - Repair Basics](Short_Circuits_-_Repair_Basics.md)

Inspect under thermal camera or use freeze spray to find the faulty component. Power IC U8500 (figure 1) is usually the culprit, check if it is getting excessively hot. Replace it with an IC from known good donor board or reputable supplier.
