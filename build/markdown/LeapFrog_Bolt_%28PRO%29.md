# LeapFrog Bolt (PRO)

This is an industrial 3D printer made by LeapFrog in 2016. With the PRO version coming out in 2017. The pro version features HIWIN linear rails while the standard version uses rods. This printer runs a Raspberry PI 3 with an modified version of OctoPrint. The mainboard uses Marlin. Since this printer uses an HDMI screen and a pi 3 it's perfect for klipperisation. I included some pictures to help with the config.
