# Nintendo Switch Console only charges from one side of the USB-C port Repair

## Problem description
Fixing an issue with the Nintendo Switch where the console only charges from one side of the USB-C port

## Symptoms
- Console only charges from one side of the USB-C port

## Solution
- Potential issue with port, M92T36, P13USB, diode packs. Full video [https://www.youtube.com/watch?v=dmwlNhDUlxU here]
  - Check port for damage or incorrect installation. If no damage and port appears fine, change M92T36
