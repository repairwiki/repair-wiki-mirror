# Nintendo Switch Charges but doesn't dock to TV Repair

## Problem description
Fixing an issue with the Nintendo Switch where the console charges but doesn't dock to TV
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Charges but doesn't dock to TV

## Solution
- Check charging port, M92T36, P13USB and filters. Ensure filters are not continuous from one side to the other
