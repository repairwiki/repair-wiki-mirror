# Nintendo Switch Drawing between 0.07a and 0.15a from charger Repair

## Problem description
Repairing a Nintendo Switch that draws between 0.07a and 0.15a from charger.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Drawing between 0.07a and 0.15a from charger

## Solution
M92T36 has shorted components. Replace M92T36 and charging port for good measure
