# PlayStation 4 Not turning on repair

## Problem description
Diagnosing and fixing issues related to "No power" on a PS4
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Not turning on

## Solution
Check power supply is outputting +5V_STBY at PSU Connector on board

Check power supply is outputting 12v at PSU Connector on board

Check for shorts around the southbridge IC

Check for Blow Fuses
