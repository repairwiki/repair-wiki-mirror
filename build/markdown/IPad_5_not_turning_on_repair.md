# IPad 5 not turning on repair

## Problem description
Fixing an issue where the iPad does not power on.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Device shows no signs of life.
- May pull between 0 and 0.6 amps from the charger

## Solution
If the device pulls zero amps from the charger this is commonly caused by a bad Tristar chip.

A short circuit on VCC_Main can also prevent the iPad from turning on.
