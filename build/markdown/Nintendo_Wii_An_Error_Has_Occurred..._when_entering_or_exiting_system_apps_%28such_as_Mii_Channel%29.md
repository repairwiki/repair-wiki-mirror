# Nintendo Wii An Error Has Occurred... when entering or exiting system apps (such as Mii Channel)

## Problem description
"An Error Has Occurred..." when entering or exiting system apps (such as Mii Channel)

## Symptoms
- "An Error Has Occurred..." when entering or exiting system apps (such as Mii Channel)

## Solution
- Disc drive isn't connected / completely dead
- Can also be due to bad Homebrew, try reinstalling default IOS IOS36, IOS58 and IOS80 from NUS downloader
