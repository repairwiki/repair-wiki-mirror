# Acer Aspire E5-773G Battery is not working repair

## Problem description
Fixing an issue with an Acer Aspire E5-773G laptop where the battery "does not work"

## Symptoms
- Battery not working

![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)

## Solution
- this laptop has an Battery enable switch (SW1) in the lower left corner (view from keyboard side)

- press the switch on startup, or assemble the keyboard case to press it down
