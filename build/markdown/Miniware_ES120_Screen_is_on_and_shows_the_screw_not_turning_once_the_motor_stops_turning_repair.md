# Miniware ES120 Screen is on and shows the screw not turning once the motor stops turning repair

## Problem description
Fixing an issue with the ES120 screwdriver where the screen is on and shows the screw not turning once the motor stops turning. Releasing and repressing the button will cause the driver to work again for ~1 second before stalling again.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Stalling motor

## Solution
Replace motor with part [https://www.digikey.com/en/products/detail/nmb-technologies-corporation/M1N10FB11G/2417078?s=N4IgTCBcDaIAoEYAsBmArEgtAOQCIgF0BfIA P14354-ND] or equivalent motor. Remove the original pinion gear with a soldering iron at 260+C to burn away previous loctite.
