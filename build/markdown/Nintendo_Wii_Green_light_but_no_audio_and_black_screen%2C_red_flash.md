# Nintendo Wii Green light but no audio and black screen, red flash

## Problem description
Green light but no audio and black screen / red flash
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Green light but no audio and black screen / red flash

## Solution
- The Wii will turn on and display nothing if either the bluetooth or Wifi board isn't connected or working properly
- Detach and reattach the bluetooth board.
- Check connector and pins to make sure they aren't damaged or corroded
- Replace bluetooth board
- If this doesn't work, repeat steps for the Wifi board
