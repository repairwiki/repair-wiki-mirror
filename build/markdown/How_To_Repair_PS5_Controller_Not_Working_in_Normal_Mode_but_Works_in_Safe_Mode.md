# How To Repair PS5 Controller Not Working in Normal Mode but Works in Safe Mode

## Problem description
The PS5 DualSense controller works normally in Safe Mode, but does not function or connect properly in Normal Mode. The controller may power on but fails to pair, respond, or operate during regular system use.

This issue is typically caused by a faulty Bluetooth/WiFi module on the main logic board.
## Symptoms
- Controller works in PS5 Safe Mode
- Controller does not respond in normal system mode
- Fails to pair or reconnect wirelessly
- May work only via USB in Safe Mode
- Firmware update does not resolve issue
- Resetting controller does not fix problem

### Diagnostic Steps
1. Reset Controller
1. * Press reset button (rear pinhole) for 5–10 seconds
1. * Re-test
1. Test via USB
1. * Connect controller via USB cable
1. * Confirm it works in Safe Mode but not in normal mode
1. Test Controller on Another System
1. * Verify PS5 controller is not at fault
1. Confirm Firmware Update
1. * Attempt PS5 firmware update
1. * If no change → hardware fault likely
1. Visual Inspection
1. * Inspect PCB for corrosion or damage around RF module

If controller consistently works only in Safe Mode → proceed to module replacement.

### Repair Steps
1. Power off System
1. Disassemble carefully
1. Remove PCB assembly
1. Locate BT/WiFi module
1. Apply flux
1. Remove faulty module with controlled hot air
1. Clean pads thoroughly
1. Install exact matching replacement module with a new one
1. Reflow evenly
1. Inspect solder joints under magnification
1. Reassemble System
