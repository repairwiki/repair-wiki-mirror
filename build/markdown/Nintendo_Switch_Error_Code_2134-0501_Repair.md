# Nintendo Switch Error Code 2134-0501 Repair

This article is a stub. You can help Repair Wiki grow by expanding it

## Problem description
Fixing a problem with a Nintendo Switch in the form of error code 2134-0501

## Symptoms
- Error Code 2134-0501

## Solution
In most scenario, this 21xx-xxxx error code is referred to bootup self-check failure, and by most case due to M92T36 PD control ic, replace it with known good one.

- Check voltages around MAX77620 (esp 1v05 rail) [https://www.retrosix.wiki/max77620-cpu-regulator Reference], if voltages good replace MAX17050 fuel gauge
