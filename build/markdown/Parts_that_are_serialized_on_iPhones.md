# Parts that are serialized on iPhones

## Summary
There are many parts that are serialized on iPhones.

Replacing some of these parts may lead to consequences like losing a function of the device or a "non genuine message".

## From the iPhone 5S until the iPhone 8 Plus only the home button is paired.
|  | Serialized Part | Home Button Click Works | Notes |
| --- | --- | --- | --- |
| iPhone 5S | Home Button | Yes | By replacing the home button Touch ID becomes unavailable |
| iPhone SE "2016" | Home Button | Yes | By replacing the home button Touch ID becomes unavailable |
| iPhone 6 | Home Button | Yes | By replacing the home button Touch ID becomes unavailable |
| iPhone 6 Plus | Home Button | Yes | By replacing the home button Touch ID becomes unavailable |
| iPhone 6S | Home Button | Yes | By replacing the home button Touch ID becomes unavailable |
| iPhone 6S Plus | Home Button | Yes | By replacing the home button Touch ID becomes unavailable |
| iPhone 7 | Home Button | No | When replacing the home button the "click" will not work and Touch ID becomes unavailble. Look into aftermarket solutions |
| iPhone 7 Plus | Home Button | No | When replacing the home button the "click" will not work and Touch ID becomes unavailble. Look into aftermarket solutions |
| iPhone 8 | Home Button | No | When replacing the home button the "click" will not work and Touch ID becomes unavailble. Look into aftermarket solutions |
| iPhone 8 Plus | Home Button | No | When replacing the home button the "click" will not work and Touch ID becomes unavailble. Look into aftermarket solutions |

## From the iPhone X apple decided to pair a quite a few parts
|  | Serialized Parts | Notes |
| --- | --- | --- |
| iPhone X | Dot Projector IR Camera Screen Proximity Sensor/Flood iluminator | The dot Projector can not be replaced but can be reparied The IR Camera cant be replaced, Face id will be lost By replacing the Screen Truetone will not work unless you copy the info from the old display. Replacing the Proximity Sensor/Flood iluminator, Face id will be come unavailable. |
