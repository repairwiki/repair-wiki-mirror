# MacBook Pro A2141camera, TrueTone, keyboard backlight not working after display replacements

## Problem description
I have replaced a broken display on A2141 with a good one, taken from similar model, now the image and back-light works fine. But the camera, the true tone and keyboard backlight is not working.

![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
Symptom 1: camera not working

Symptom 2 : True Tone not working

Symptom 3 : keyboard backlight not working
## Solution
  - Replace the original display cable with one from A1707 as suggested in logi.wiki.**

### Diagnostic Steps
Test the original non working display on known good A2141 : display not working

Install a known working display I get the symptoms described above

### Repair Steps
Disassemble the motherboard

Replace the original display cable with one from A1707

Assemble back
