# Samsung Galaxy S22 Ultra No Signal fix

## Problem description
The problem happens mainly after a drop and these are the symptoms you will see in your device:

- Very low signal
- No signal at all
- No signal sign at the Top

![No signal icon](images/2/25/No_signal_icon.png)

  - important note:** Make sure you have the following problems before proceeding to the repair. If sympoms are not same then you do not have this problem and do not proceed to this solution.

- Check for Baseband Version if available in settings(if available then proceed)
- Insert SIM (pin enabled) to make sure the phone recognises the sim

## Solution
- Visually check the device
- Try with known good Dock Assembly
- Try with known good GSM antenna(shown in the picture below)

![GSM ANTENNA](images/0/09/GSM_ANTENNA.jpg)

- Carefully check the top and bottom connectors of gsm antenna, Sometimes they don't look broken, if you have any doubt on a connector just replace it, see the pic for reference below.

![CONNECTOR COMPARISON](images/b/ba/CONNECTOR_COMPARISON.png)
![top and bottom connectors](images/0/03/Top_and_bottom_connectors.png)
