# IPhone XR Compass/Gyroscope not working

## Problem description
If your Gyroscope is not working anymore, the problem might be with a little cable going from the wireless charging coil to the housing. This cable is responsible for proper functioning of the gyroscope. If you damaged this cable while replacing the back cover or battery, you need to replace the wireless charging coil.
