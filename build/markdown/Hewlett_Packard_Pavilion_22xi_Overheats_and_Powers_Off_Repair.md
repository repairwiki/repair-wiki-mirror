# Hewlett Packard Pavilion 22xi Overheats and Powers Off Repair

## Problem description
Monitor work for some time, a few minutes then it turns off and can't be power on unless it cools down.![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Overheats then powers off

## Solution
- Replace eeprom (25xx), now don't use same one, use from another manufacturer, when you remove the old eeprom you have to read it (dump its contents) write that content in another eeprom and put it back in its place. The problem with this monitor is that the eeprom has a problem, it stops working when it heats up, the problem is in the eeprom.
