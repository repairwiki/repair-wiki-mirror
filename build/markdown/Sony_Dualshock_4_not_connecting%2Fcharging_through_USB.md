# Sony Dualshock 4 not connecting/charging through USB

## Problem description
Controller not connecting/charging through USB
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Does not charge
- Does not sync with a console

## Solution
- Check USB port
- If controller has been opened, check ribbon cable/connector for damage
- Check for open fuse (charging) / shorted USB data (D+/D-) protection component (communication) on USB-connector board
