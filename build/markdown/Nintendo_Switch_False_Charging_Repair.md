# Nintendo Switch False Charging Repair

## Problem description
False Charging (recognizes charger on both sides and gives charging symbol but decreases %. Will show charging symbol but drains power (back-feeding)

## Symptoms
- Says that it is charging but actually draining the battery

## Solution
Check M92T36, P13USB and BQ24193. Replace as necessary.
