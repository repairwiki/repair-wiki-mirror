# Nintendo Switch Draws 0.00a Repair

## Problem description
Fixing an issue where the Switch draws 0.00a from charger or bench PSU
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- 0mA power draw

## Solution
Port, Port Fuse, M92T36, or PI3USB and right most (in readable orientation) Filter, BQ24193.

Measure/check all of those and replace as necessary.
