# Nintendo Switch Joycon only works wirelessly and still charges Repair

## Problem description
Repair of an issue where the Joy-con only works wireless, but still charges on the Switch.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Joy-con only works wireless
- Joy-con still charges

## Solution
Replace side-rail ribbon. It is probably damaged.
