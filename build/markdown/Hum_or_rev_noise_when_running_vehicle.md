# Hum or rev noise when running vehicle

## Problem description
When listening from outside vehicle noise not herd. Inside vehicle noise is herd from body.

## Possible areas of Problem:
- Possible areas of problem: With stethoscope listen to fuel pressure damper set (on fuel rail). If pulsation is herd suspect damper

## Solution
Fuel Pressure Pulsation Damper Assy was the problem
