# Xbox Elite Controller Series 2 issues with the analog sticks repair

## Problem description
Software does not detect full extension of joystick, only part way.

Analog stick drifting or jumping around.![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Software does not detect full extension of joystick.
- Analog stick drifting or jumping around.

## Solution
- There are four pots. (two for each analogue), they should be cleaned first and if they are used up, then replaced, the whole analog stick with the mechanism can be changed or only the pots. The mechanism is special for the Elite series 2, but pots are the same as other versions.
- These pots will likely not center properly after replacement, you have to rotate them before soldering them in the correct center position, on PCBs without plated through holes you can bend over the pins to make this easier. In extreme cases you will need to shave the corner locating pegs.
