# Nintendo Switch Only slow charges (0.4a - 0.6a) Repair

## Problem description
Fixing an issue where the Switch charges but very slowly. Drawing between 0.4A and 0.6A from the charger.

## Symptoms
- Only slow charges (0.4a - 0.6a)

## Solutions
- Change M92T36 or check 100k resistors above M92T36
