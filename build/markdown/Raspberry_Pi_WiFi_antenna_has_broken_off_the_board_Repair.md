# Raspberry Pi WiFi antenna has broken off the board Repair

## Problem description
The Wi-Fi antenna has broken off the board.

- Pi **3** (B only)

![Pi 3B Wi-Fi antenna](images/f/f8/Pi3B_Wifi_Antenna.jpg)

## Symptoms
- Wi-Fi antenna has broken off the board.

## Solution
Replace with one of the following parts:

- `SLDA52-2R450G-S1`
