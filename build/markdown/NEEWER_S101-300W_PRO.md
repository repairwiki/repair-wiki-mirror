# NEEWER S101-300W PRO

This is a flash strobe monolight device used by photography professionals to illuminate their shots.

![Monolight](images/3/3f/NEEWER_S101-300W_PRO.webp)
This device is rated for 300W of power usage, features an integrated noble gas lamp and has a mount for attaching other accessories to it, as umbrellas and the like. It also features remote capabilities, being able to be triggered by a remote controller that can control up to 16 channels.
