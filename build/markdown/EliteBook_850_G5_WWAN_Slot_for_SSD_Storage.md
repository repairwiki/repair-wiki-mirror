# EliteBook 850 G5 WWAN Slot for SSD Storage

## Problem description
User wants to expand storage using the WWAN slot (separate from the larger main storage)
## Solution
These three criteria must be met for the storage to work:

1. Protocol: The WWAN slot only supports NVMe. Any storage labeled as SATA will not work.
1. Size: The slot is the 2242 size. If you have a 2230 size, an adapter to 2242 will work. I use an adapter and the back case presses against the adapter but no issues.
1. Key: The slot only supports B keying. So, you can either have a 2242 with B keying or a 2230 with a B+M adapter that increases the size to 2242.
