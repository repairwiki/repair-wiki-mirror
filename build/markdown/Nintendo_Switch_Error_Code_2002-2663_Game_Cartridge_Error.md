# Nintendo Switch Error Code 2002-2663 Game Cartridge Error

![Nintendo Switch Error 2002-2663](images/c/c9/Nintendo_Switch_Error_2002-2663.png)

## Problem description
Nintendo Switch that gets error 2002-2663 when you insert the Game Cartridge.

It will boot up fine with no game inside

## Symptoms
- Error 2002-2663
- == Solution Repair Steps ==

1. Try rebooting the game console
1. Try a new game reader
1. Try reflowing or reballing  IC on the other side of the game cartridge connector
1. Otherwise, try replacing it
