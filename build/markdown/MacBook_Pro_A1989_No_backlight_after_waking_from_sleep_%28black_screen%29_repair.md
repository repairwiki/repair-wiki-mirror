# MacBook Pro A1989 No backlight after waking from sleep (black screen) repair

## Problem description
Black screen after returning from sleep (no backlight but has picture)
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- MacBook works normally, but after waking up from sleep there is no backlight anymore

## Solution
Lid detect sensor (J4800 or J4801) missing PP1v8_SLPS2R or deffective. Ran a Jumper from CB402 to the cap on top of J4801.
