# IPad Pro 9.7 Not Turning On Repair

## Problem description
Fixing an issue where the iPad does not power on.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Device shows no signs of life
- When plugged in to a charger the iPad pulls zero amps.

## Solution
Very common on this model for the Tristar chip to fail.
