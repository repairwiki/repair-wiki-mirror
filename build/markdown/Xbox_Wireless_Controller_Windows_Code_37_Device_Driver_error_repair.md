# Xbox Wireless Controller Windows Code 37 Device Driver error repair

## Problem description
Getting an error stating Windows cannot initialize the device driver for this hardware. (Code 37)
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Windows cannot initialize the device driver for this hardware. (Code 37)

## Solution
Open Windows Update and ensure KB2685811 is installed.
