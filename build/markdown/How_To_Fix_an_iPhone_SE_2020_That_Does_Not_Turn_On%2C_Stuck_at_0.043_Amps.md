# How To Fix an iPhone SE 2020 That Does Not Turn On, Stuck at 0.043 Amps

## Problem description
Diagnosis and repair of an iPhone SE 2020 that does not power on. After prompting the phone to boot on DC power supply the current stays at 43mA.
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- No current draw before prompt to boot on DC power supply
- Phone shows no signs of life

## Solution
Check for missing power rails and loose coils around the CPU and PMIC.
