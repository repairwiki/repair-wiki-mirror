# Common inkjet printer problems and solutions

| Problem | Solutions |
| --- | --- |
| Inkjet printing carriage is stuck at the side of the printer (inkjet) |  * Manually turn the gears as shown in [https://www.youtube.com/watch?v=lK1-vEWMPEY this video] |
| Random black spots on color print (inkjet) |  * Clean the dry ink under the printing head. If a proper cleaning solution is not available use ammonia-based glass cleaner (i.e. Windex). Do not use isopropyl alcohol. |
| After disassembling and reassembling the printer, control panel LEDs blinks randomly |  * Check that all ribbon cables are securely connected. |
| Printer reports inexistent paper jam (inkjet) |  * Clean the round-shaped plastic film that provides rotational info to the encoder. |
| Printed characters are blurry (inkjet) |  * Clean the long, thin plastic strip that provides longitudinal position information to the encoder. |
