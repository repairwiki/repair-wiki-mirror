# MacBook Pro A1707 Touchbar freeze fix

## Problem description
An easy fix to a freezing touchbar issue on A1707 MacBook Pro
![Example image (Figure 1) -- No image yet. Help expand this page by uploading it!](images/3/30/Placeholder_image.jpg)
## Symptoms
- Touchbar freezes during normal operation
- Touchbar freezes after changing volume or brightness

## Solution
Press Cmd + Space to open Spotlight. Touchbar responds again.
